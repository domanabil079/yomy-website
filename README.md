# يومي | YOMY — Demo Website

واجهة تجريبية عربية RTL لموقع تنظيم حياة الطالب، مبنية بـ HTML/CSS/JavaScript فقط لتسهيل رفعها على GitHub ونشرها على Vercel دون اشتراك في أداة بناء مواقع.

## الموجود في النسخة التجريبية
- لوحة رئيسية متجاوبة للموبايل والكمبيوتر.
- مهام قابلة للإضافة ووضع علامة إنجاز.
- إضافة حصص للجدول.
- اختيار مدينة (المواعيد المعروضة تجريبية).
- واجهة محادثة محاكاة للمساعد.
- اختيار الحالة المزاجية.
- خلفية متحركة وتصميم زجاجي.
- لا توجد مفاتيح API أو أسرار.

## مهم
هذه نسخة Frontend Demo. المحادثة ليست متصلة بنموذج ذكاء اصطناعي، ومواقيت الصلاة تجريبية، والبيانات لا تُحفظ بعد إغلاق الصفحة. تسجيل الدخول، قاعدة البيانات، إشعارات Telegram، وتدفق تحويل المحادثة لمشرف بشري تحتاج Backend وإعداد خدمات خارجية.

## الرفع على GitHub من الموبايل
1. فك ضغط `yomy-website.zip` على جهازك إن أمكن.
2. افتح https://github.com وسجّل الدخول.
3. اضغط `+` ثم `New repository`.
4. سمّ المستودع `yomy-website` واجعله Public أو Private ثم أنشئه.
5. من صفحة المستودع اختر `Add file` ثم `Upload files`.
6. ارفع `index.html` و`README.md` و`vercel.json` (ملفات المشروع نفسها، وليس ملف ZIP فقط) ثم اضغط `Commit changes`.

## النشر على Vercel
1. افتح https://vercel.com وسجّل الدخول باستخدام GitHub.
2. اضغط `Add New` ثم `Project`.
3. اختر مستودع `yomy-website` ثم `Import`.
4. بما أن المشروع HTML ثابت، اترك إعدادات البناء الافتراضية المناسبة أو اختر Other إن ظهر، ولا تضف Build Command أو Output Directory غير مطلوبين.
5. اضغط `Deploy`.
6. بعد نجاح النشر افتح رابط `*.vercel.app`.

## التحديث
أي تعديل ثم `Commit changes` على GitHub سيؤدي عادةً إلى نشر جديد تلقائيًا على Vercel بعد ربط المستودع.

## تشغيل محلي
افتح `index.html` في المتصفح. لا يحتاج تثبيت حزم.
